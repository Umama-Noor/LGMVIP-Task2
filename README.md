# LGMVIP Task 2 - Web Application

A Web Application built as part of LetsGrowMore Virtual Internship Program (LGMVIP). Fetches user data from an API and displays it in a clean, responsive card layout.

## ✨ Features
- Fetch users from API
- Display users in card layout
- Get Users button
- Loading state
- Responsive design for mobile and desktop
- Clean and modern UI

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript
- React
- API Integration

## 🚀 How To Use
1. Download / Clone this repository
2. Open `index.html` in any browser
3. Click "Get Users" to fetch users
